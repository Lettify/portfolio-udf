# Portfolio UDF

Projeto avaliativo da disciplina **Desenvolvimento Front-end para Web** (UDF), consistindo na construção de um portfólio pessoal em HTML utilizando o framework Bootstrap.

## Tecnologias utilizadas

- **HTML5** — estrutura semântica da página principal (`index.html`).
- **Bootstrap `v6.0.0-alpha.1`** — estilização, grid responsivo e componentes interativos carregados localmente (sem dependência de CDN).

## Estrutura do repositório

```text
portfolio-udf/
├── css/            # Arquivos CSS compilados do Bootstrap (ex.: bootstrap.min.css) e source maps
├── js/             # Arquivos JS compilados do Bootstrap (ex.: bootstrap.bundle.min.js) e source maps
├── index.html      # Página principal do portfólio
└── README.md       # Documentação do projeto
```

## Como executar localmente

Não é necessário instalar dependências ou executar etapa de build.

1. Clone o repositório:
   ```bash
   git clone https://github.com/Lettify/portfolio-udf.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd portfolio-udf
   ```
3. Abra o arquivo `index.html` diretamente no navegador (ou utilize uma extensão como o **Live Server** no VS Code).
