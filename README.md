# Portfolio UDF

Projeto avaliativo da disciplina **Desenvolvimento Front-end para Web** (UDF), consistindo em uma landing page de portfólio pessoal para **Michael Silva**, reunindo projetos, trajetória acadêmica e hobbies em um layout responsivo com tema escuro e destaque em roxo.

## Tecnologias utilizadas

- **HTML5** — estrutura da página única.
- **Bootstrap** — grid responsivo, tema escuro, menu lateral mobile, cards, badges e formulários carregados localmente.
- **CSS3** — ajustes de cor roxa, tamanho das imagens e efeito simples nos cards.
- **JavaScript** — interatividade básica:
  - Filtro entre *Todos*, *Projetos* e *Hobbies*;
  - Validação simples do formulário de contato com mensagem na tela;
  - Fechamento automático do menu mobile ao clicar em um link.

## Como executar localmente

Não é necessário instalar dependências ou executar etapa de build.

1. Clone o repositório:
   ```bash
   git clone https://github.com/Lettify/portfolio-udf.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd portfolio-udf
   ```
3. Abra o arquivo `index.html` diretamente no navegador (ou utilize uma extensão como o **Live Server** no VS Code).
